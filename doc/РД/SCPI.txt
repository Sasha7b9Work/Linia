   *** Обновление прошивки ***
+------------------------------------------+--------------------------------------------+
| Orange Pi                                | stm32                                      |
+------------------------------------------+--------------------------------------------+
|:UPGRADE:START <size> <crc32>             |                                            |  -> Запрос начала обновления
|                                          |:UPGRADE:START                              | <-  Разрешение обновления
|:UPGRADE:HEAD <num_block> <size> <crc32> |                                            |  -> Информация о записываемом блоке                  <---+
|                                          |:UPGRADE:HEAD <num_block> <size> <crc32>    | <-  Подтверждение информации о записываемом блоке        |
|<блок двоичных данных>                    |                                            |  -> Передача блока данных                                |
|                                          |:UPGRADE:CONTENT <num_block> <size> <crc32> | <-  Подтверждение приёма                              ---+
|:UPGRADE:END <size> <crc32>               |                                            |  -> Вся прошивка передана
|                                          |:UPGRADE:END <size> <crc32>                 | <-  Вся прошивка принята
|                                          |                                            |
|                                          |:UPGRADE:ERROR                              | <-  Произошла ошибка. Нужно повторить передачу
+------------------------------------------+--------------------------------------------+
